Private database backup

The database contains all classes, stable student mappings, assessment snapshots, classifications and correction/import history. It is private and excluded from Git.

A consistent SQLite backup is also saved under data/private/backups/. Keep it in a secure location separate from this computer.

Transfer or restore

Stop Studentdash. On the destination computer run:

.venv\Scripts\python.exe -m app.restore BACKUP.sqlite3 data\restored\studentdash.sqlite3

Restore requires a new destination and never replaces an existing database. Then set STUDENTDASH_PRIVATE to the absolute path of data/restored before running start.bat. You do not need to reimport old classifications.
