# Your ArborSynapse folder

Keep the whole folder locally. In OneDrive choose **Always keep on this device**.
Open **Start Studentdash.cmd** for results and the tree; keep its window open.
Results rings show earned/possible marks. Click a ring for test/question evidence.
Classifications appear with your results. Confidence stays in your browser, separate
from teacher updates; use **Export confidence** for a backup. Use the same browser
and keep the same package folder. Only one viewer can run on port 8765 at a time.
