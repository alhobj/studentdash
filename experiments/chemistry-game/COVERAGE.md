# Game syllabus coverage

All 22 sections in the existing local syllabus reference have an introductory
investigation. This is not full coverage of every statement, HL extension or
practical skill. Quest completion is game practice, not assessment evidence.
R1.4 is labelled AHL; other sections here use selected introductory concepts.

Use **Explore syllabus sections** in the game to see current availability.
Prerequisites are proposed game routes, not official syllabus dependencies.
