Try a fixed scenario

For a taxi model C = 2d + 3, find the cost for d = 8 km.

Worked explanation

C = 2(8) + 3 = 19. The intercept is the starting charge; the slope is cost per kilometre.

Try a fixed scenario

For y = 2(x − 3)² + 4, what is the minimum y-value?

Worked explanation

The squared term is non-negative and a is positive. The minimum occurs at x = 3 and equals 4.

Hands-on explorer · SL 2.2

Restrict a domain and undo a function

Start with: SL 2.2 small steps

Use f(x) = 2x + 3 on a closed input interval. Compare its graph with its inverse and the reflection line y = x. Domain restrictions carry over to the inverse's range.

Try a fixed scenario

If f(x) = 2x + 3, find f⁻¹(11).

Worked explanation

Undo +3, then divide by 2: (11 − 3)/2 = 4. An inverse reverses input and output; it is not a reciprocal.

Hands-on explorer · SL 2.3

Add graphs and inspect their features

Start with: SL 2.3 small steps

Compare f(x)=x²−4, g(x)=mx+b, their sum and their difference. Predict intercepts and sketch the selected graph on paper with labelled axes before revealing its features.

Try a fixed scenario

For f(x)=x²−4 and g(x)=x, find (f+g)(2).

Worked explanation

f(2)=0 and g(2)=2, so their sum is 2. Subtracting graphs instead gives −2.

Try a fixed scenario

A seasonal model is y = 4 sin(30x°) + 10. Find its period.

Worked explanation

Period = 360/30 = 12; amplitude 4; principal axis y=10. A periodic model is suitable for repeating seasonal behaviour, not unlimited growth.
