Import results

Upload the original grading workbook. Studentdash reads a copy; it never edits your Excel file. Use the same ClassID on later imports, even if you rename the file.

Profile and curriculum for a new class

Existing classes keep their captured profile, curriculum and default level.

Do not guess levels from filenames or question prefixes. An optional Level column in Overview overrides this default. Without levels, recorded results are used as supplied.

Workbook structure

Overview: names in column A, from row 2. Optional StudentID and Level columns may be used, but are not required. Distinct names are required to match copied score-sheet rows.

Assessment sheets: copy Assessment blueprint and name the copy DD.MM.YYYY. Question labels are in row 1, maximum marks in row 2, and student results from row 3. Questions end before the Marks column. Overview, Assessment blueprint and Grade boundaries are never assessments.

Blank marks remain pending. A/X/FRAV = absent; E = exempt; M = missing; P = pending. A zero is a graded zero. The “x for absence” column overrides question marks with a warning. Administrative totals, percentages and grades are not imported as questions.

Recalculate and save formula-based scores in Excel before upload. Missing formula caches are reported; Studentdash never evaluates arbitrary Excel formulas.
